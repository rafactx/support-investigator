# Processing returns and refunds

A return applies to an order that was already invoiced. It reverses the goods flow and, separately, the money flow.

## Steps

1. The customer or the seller opens a return request listing the items and the reason.
2. The seller approves the request and issues return shipping instructions.
3. The returned items are received and inspected at the warehouse.
4. The seller issues the return fiscal document and triggers the refund.
5. The refund goes back to the original payment method; timing depends on the payment provider.

## Partial returns

Only some items or some quantities may be returned. The refund covers the returned items plus any proportional shipping the seller policy allows.

## Support checklist

- Is the order invoiced? If not, it is a cancellation, not a return.
- Is the request inside the return window?
- Has the warehouse received the goods? Refunds normally wait for receipt.

Support investigations stay read-only: recommend the next step and hand off to the seller or a specialist to execute it.
