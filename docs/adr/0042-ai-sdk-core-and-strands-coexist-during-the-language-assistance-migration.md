# AI SDK Core and Strands coexist during the Language Assistance migration

ADR-0039/0040 name AI SDK Core with the Amazon Bedrock provider as the target — and eventually only — LLM abstraction for this project. Intake extraction needed a bounded, schema-constrained extraction call (`src/language-assistance/bedrock-language-assistance.ts`): ticket text in, a Zod-validated `ExtractedIntakeFields` out, no tool loop, no agent. `@strands-agents/sdk`'s own model interface is built around that SDK's own streaming/tool-call event protocol (`ModelStreamEvent`s), not a plain `generateText` + structured-output call, so reusing `src/model/create-model.ts`'s `BedrockModel` for this new seam would have meant either wrapping Strands' agent loop around a task that needs no loop, or reaching past AI SDK's own structured-output primitive to hand-parse Strands' event stream.

This change instead adds `ai` v7 and `@ai-sdk/amazon-bedrock` 5.x as new dependencies and builds intake extraction directly on `generateText`/`Output.object`, leaving `@strands-agents/sdk` and `src/agent/investigate.ts`'s model-driven loop completely untouched. Both LLM abstractions exist in `package.json` simultaneously as of this change. This is not a wiring gap left implicit: it is step 3 of the migration sequence the tooling research doc (`docs/research/2026-07-30-ai-sdk-and-tooling-recommendation.md`) already lays out — "Replace Strands model orchestration with AI SDK Core over Bedrock for bounded extraction and explanation" — before step 7's later removal of Strands once the `/investigate` cutover ships.

## Consequences

Two Bedrock-calling code paths now exist side by side: `src/model/create-model.ts` (Strands, the deployed `/investigate` agent loop, unchanged) and `src/language-assistance/bedrock-language-assistance.ts` (AI SDK Core, the bounded extraction call, and the future explanation-improvement call). Both share the same verified inference-profile model id and `us-east-1` default region, and both reach Bedrock through `bedrock:InvokeModel` only — `generateText` never streams, so no new IAM grant was needed alongside ADR-0016's existing one. `@strands-agents/sdk` is not removed by this change; its removal waits until the old `/investigate` route itself is cut over rather than merely superseded by `/investigations`.

**Update:** done. `/investigate` and its Strands `Agent`/`McpClient`/`Model` usage are removed with no compatibility layer, `@strands-agents/sdk` is out of `package.json`, and AI SDK Core (`ai` + `@ai-sdk/amazon-bedrock`) is the only LLM abstraction anywhere in the codebase. See ADR-0046.
